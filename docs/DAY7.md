# Day 7 Verification Guide

This document outlines the procedure to verify the Day 7 checkpoint for the AiFinPay Autonomous Growth OS.

## Reproducible Verification

The entire approval → gate → publish workflow can be verified using the provided script. This script ensures that all steps are executed correctly inside the containerized environment.

### Prerequisites

- The Docker stack must be running: `make up`
- The database must be migrated: `make migrate`

### Running the Verification

To run the automated verification script:

```bash
make verify
```

The script performs the following actions:
1. Applies any pending database migrations.
2. Creates a new marketing campaign via the API.
3. Polls the API until a content draft is generated by the agents.
4. Approves the draft on behalf of a human operator.
5. Verifies that the `content_approved` event is recorded in the audit trail.
6. Triggers the publication gate via the API.
7. Confirms that the publication task is successfully enqueued.

## Manual Verification with `curl`

When performing manual API calls, ensure you use single-quoted JSON bodies to avoid shell interpretation issues. The API is accessible at `http://localhost:8000`.

### Example: Approving a Draft

```bash
curl -s -X POST 'http://localhost:8000/api/v1/content/<content_id>/approve' \
  -H 'Content-Type: application/json' \
  -d '{"approved_by":"Human Operator"}'
```

### Example: Triggering Publication

```bash
curl -s -X POST 'http://localhost:8000/api/v1/content/<content_id>/publish'
```

## Troubleshooting

If the verification fails:
1. Check the worker logs: `make logs`
2. Ensure both ports 3000 (Dashboard) and 8000 (API) are public if running in Codespaces.
3. Verify all tests pass: `make test`
