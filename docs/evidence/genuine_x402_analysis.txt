### How to Get Live AiFinPay API Access

Based on official documentation (https://aifinpay.io/llms.txt and https://api.aifinpay.io/.well-known/x402.json):

**Step 1: Generate Ed25519 Keypair Locally**
```bash
# Python
python -m aifinpay_agent.keygen

# Node
npx @aifinpay/agent new-wallet
```

**Step 2: Get Agent Pubkey and Store Private Key**
- Keep private key in environment (e.g., AGENT_PK)
- AiFinPay never creates or stores private keys

**Step 3: Create Seat PDA on Solana Mainnet**
- Call `reserve_seat_sol` on Solana program `5g9zWHF1Vv6GiGpA2ZbJQbSCDZd5hAk9AyvabRJvKFx2`
- Requires funded wallet on Solana MAINNET (not devnet)
- Minimum payment: $1.00 USD equivalent in SOL
- This creates a Seat PDA on-chain that grants API access

**Step 4: Use Live API with Ed25519 Auth**
- GET /nonce (60s TTL)
- POST /invoice with x-agent-pubkey, x-nonce, x-signature headers
- Sign: Ed25519(SHA256("AiFinPay-x402:{nonce}:{agent_pubkey}"), keypair)
